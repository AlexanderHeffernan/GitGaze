Features

Small app. Lots of care.

Six ways to wear it

Each label shows today’s count, with your streak if you want it. Pick a dial, waveform, mosaic or ribbon. On Windows, the tray shows a compact dial.

Celebrations that mean something

The particles form your actual increase. GitGaze only celebrates once GitHub confirms new contributions.

~/gitgaze git push
Enumerating objects: 9, done.
To github.com:you/gitgaze.git
   4677d8a..1a3b660  main -> main
GitGaze ✦ +3 today, 12-day streak

Notices your pushes

Turn on push detection and GitGaze refreshes the moment a git push succeeds, in any repository. It uses Git’s built-in Trace2 events, with no hooks to install.

Questions & answers

Is it free?

Yes. GitGaze is open source under the MIT licence. There’s no subscription and nothing to sign up for.

What does it count?

Your GitHub contribution calendar: commits, pull requests, issues and reviews, plus the private activity your account can see. It doesn’t only count commits.

Does it see my token?

GitGaze asks GitHub CLI for your session token and keeps it in memory. It never saves the token, changes your CLI login or asks for extra scopes.

How does it update?

It checks GitHub releases every few hours and installs signed updates in place when you agree. Every update is verified against a key built into the app.

Why is macOS or Windows warning me?

Releases aren’t notarised or code-signed yet, so the first launch may ask you to confirm. The install scripts check each download’s checksum.

Can I build it myself?

Yes. One codebase builds both apps: a web UI inside a small Tauri shell written in Rust. See the contributing guide.
