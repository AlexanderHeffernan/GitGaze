GitGaze for macOS

GitHub activity in your menu bar.

The menu-bar item shows today’s count. Open it to see your streak, daily best and contribution history.

GitGaze also counts other GitHub activity besides commits, including private contributions your account can see.

Install GitGaze

macOS 14 or later · Apple Silicon and Intel

In Terminal, install GitHub CLI with Homebrew: brew install gh. Sign in with gh auth login --hostname github.com, then run:

curl -fsSL https://raw.githubusercontent.com/AlexanderHeffernan/GitGaze/main/install.sh | bash

The script checks the release checksum, installs in ~/Applications without administrator access, and opens GitGaze. Look for the contribution count at the top right of your Mac’s menu bar.

Download ZIP instead: unzip it, move GitGaze.app to Applications, then open it. If macOS blocks this first launch, use System Settings → Privacy & Security → Open Anyway only if you trust the release.
