Get GitGaze.

Install platform

macOS 14+ · Apple Silicon and Intel

Terminal
curl -fsSL https://raw.githubusercontent.com/AlexanderHeffernan/GitGaze/main/install.sh | bash

Paste into Terminal. GitGaze opens in your menu bar, near the clock.

Required setup for script and ZIP
  1. No brew? Install Homebrew and follow the shell setup it prints under “Next steps.”
  2. Install GitHub CLI with brew install gh.
  3. Sign in with gh auth login --hostname github.com, then run the script or use the ZIP below.

Prefer a manual install? Download ZIP, unzip it, move GitGaze.app to Applications, then open it. If macOS blocks the first launch, choose System Settings → Privacy & Security → Open Anyway only if you trust the release.
