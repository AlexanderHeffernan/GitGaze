Install on Mac

Make it yours.

For macOS 14 and later, on Apple Silicon and Intel. Install GitHub CLI and sign in first with gh auth login --hostname github.com.

Terminal
curl -fsSL https://raw.githubusercontent.com/AlexanderHeffernan/GitGaze/main/install.sh | bash

Verifies the release checksum and installs in ~/Applications. No administrator access needed.
